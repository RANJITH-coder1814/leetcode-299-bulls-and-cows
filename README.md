# 299. Bulls and Cows

## Problem Statement

You are playing the Bulls and Cows game with your friend.

- A **Bull** is a digit in the guess that matches the secret number in both value and position.
- A **Cow** is a digit that exists in the secret number but is placed in the wrong position.

Given two strings `secret` and `guess`, return the hint in the format `"xAyB"` where:

- `x` = number of bulls
- `y` = number of cows
